## 予約作成処理（楽観ロック）

### 概要

## 予約枠編集処理（定員変更）

### 概要
スタッフが予約枠の定員を変更する処理。既存予約数未満には変更できません。

### 正常系フロー

```
Client          Controller        Service           Repository        DB
  │                 │                 │                  │             │
  │ PATCH /api/     │                 │                  │             │
  │ staff/slots/10  │                 │                  │             │
  ├────────────────>│                 │                  │             │
  │ UpdateSlotRequest(capacity=10)    │                  │             │
  │                 │                 │                  │             │
  │                 │ updateSlot(slotId, request)        │             │
  │                 ├────────────────>│                  │             │
  │                 │                 │                  │             │
  │                 │                 │ @Transactional開始             │
  │                 │                 │                  │             │
  │                 │                 │ findById(10)     │             │
  │                 │                 ├─────────────────>│             │
  │                 │                 │                  │ SELECT ...  │
  │                 │                 │                  ├────────────>│
  │                 │                 │                  │             │
  │                 │                 │ Slot(capacity=5) │             │
  │                 │                 │<─────────────────┤             │
  │                 │                 │                  │             │
  │                 │                 │ countBySlotIdAndStatus(10, RESERVED)
  │                 │                 ├─────────────────>│             │
  │                 │                 │                  │ SELECT COUNT(*)
  │                 │                 │                  ├────────────>│
  │                 │                 │                  │             │
  │                 │                 │ 予約数=3         │             │
  │                 │                 │<─────────────────┤             │
  │                 │                 │                  │             │
  │                 │                 │ 定員チェック     │             │
  │                 │                 │ 新定員(10) >= 予約数(3)? YES   │
  │                 │                 │ → OK             │             │
  │                 │                 │                  │             │
  │                 │                 │ slot.setCapacity(10)           │
  │                 │                 │                  │             │
  │                 │                 │ save(slot)       │             │
  │                 │                 ├─────────────────>│             │
  │                 │                 │                  │ UPDATE slots│
  │                 │                 │                  │ SET capacity=10
  │                 │                 │                  ├────────────>│
  │                 │                 │                  │             │
  │                 │                 │ @Transactional COMMIT          │
  │                 │                 │                  │             │
  │                 │                 │ SlotResponse     │             │
  │                 │<────────────────┤                  │             │
  │                 │                 │                  │             │
  │ 200 OK          │                 │                  │             │
  │ SlotResponse(capacity=10, reservedCount=3, remaining=7)           │
  │<────────────────┤                 │                  │             │
  │                 │                 │                  │             │
```
