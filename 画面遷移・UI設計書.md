## 画面一覧

### 認証画面（全ユーザー共通）

| 画面ID | 画面名 | パス | 説明 |
|--------|--------|------|------|
| A-01 | ログイン画面 | `/login` | メール/パスワードログイン、Googleログイン |

| 画面ID | 画面名 | パス | 説明 |
|--------|--------|------|------|

| U-04 | 予約完了画面 | `/reservations/success` | 予約完了メッセージ |
| U-05 | 自分の予約一覧画面 | `/reservations/my` | 進行中の予約一覧 |
| U-06 | 予約履歴画面 | `/reservations/history` | 全予約履歴（キャンセル済み含む） |

### スタッフ画面（STAFF）

| 画面ID | 画面名 | パス | 説明 |
|--------|--------|------|------|
| S-01 | スタッフダッシュボード | `/staff` | スタッフのホーム画面 |

## 共通コンポーネント

### ヘッダー

**表示内容**:
- ロゴ / アプリ名
- ナビゲーションメニュー
- ユーザー情報（ログイン後）
- ログアウトボタン

**ユーザーロール別メニュー**:

| ロール | メニュー項目 |
|--------|-------------|
| 未ログイン | - 予約枠一覧<br>- ログイン<br>- 新規登録 |
| USER | - 予約枠一覧<br>- 自分の予約<br>- 予約履歴<br>- ログアウト |
| STAFF | - ダッシュボード<br>- メニュー管理<br>- 予約枠管理<br>- 全予約一覧<br>- ログアウト |

---

### フッター

- コピーライト
- お問い合わせリンク（任意）

---

### エラーメッセージ

**表示位置**: 画面上部（トースト通知 or アラート）

**色分け**:
- 成功: 緑系
- エラー: 赤系
- 警告: 黄色系
- 情報: 青系

## 認証画面

### A-01: ログイン画面

**パス**: `/login`

**表示内容**:
```
┌─────────────────────────────────────┐
│        予約システム - ログイン        │
├─────────────────────────────────────┤
│                                     │
│  メールアドレス                       │
│  [__________________________]       │
│                                     │
│  パスワード                          │
│  [__________________________]       │
│                                     │
│  [    ログイン    ]                  │
│                                     │
│  ──────── または ────────            │
│                                     │
│  [ G  Googleでログイン ]             │
│                                     │
│  アカウントをお持ちでない方は          │
│  [新規登録はこちら]                   │
│                                     │
└─────────────────────────────────────┘
```

**機能**:
- メールアドレス、パスワード入力
- バリデーション（メール形式、必須チェック）
- ログインボタン → `POST /api/auth/login`
- Googleログインボタン → `GET /api/auth/google`
- 新規登録リンク → `/signup`

**エラー表示**:
- メール/パスワード不正
- メールアドレス未確認

### プロンプト例（予約枠一覧画面）

```
# 予約システム - 予約枠一覧画面

## 概要
定員制の予約システムのフロントエンド（React）を作成してください。
バックエンドはREST APIで提供されており、Axiosで接続します。

## 技術スタック
- React 18+
- React Router
- Axios
- CSS（TailwindまたはMaterial-UI）

## 画面：予約枠一覧画面

### URL
`/` または `/slots`

### 認証
不要（未ログインでも閲覧可）

### API
- エンドポイント: `GET /api/slots`
- クエリパラメータ: `from`, `to`, `menuId`
- レスポンス:
```json
[
  {
    "id": 10,
    "menuName": "30分コース",
    "startAt": "2025-12-15T10:00:00+09:00",
    "endAt": "2025-12-15T10:30:00+09:00",
    "capacity": 5,
    "reservedCount": 3,
    "remainingCapacity": 2,
    "status": "OPEN"
  }
]
```

### 画面要素
1. ヘッダー
   - ロゴ: "予約システム"
   - ナビゲーション: ログイン、新規登録

2. フィルタエリア
   - 日付範囲: 開始日、終了日（DatePicker）
   - メニュー: ドロップダウン（全メニュー取得）
   - 検索ボタン

3. 予約枠リスト
   - カード形式で表示
   - 各カード:
     - メニュー名（大きく表示）
     - 日時（yyyy-MM-dd HH:mm形式）
     - 残席数 / 定員（色分け：残席少ない場合は赤）
     - 「詳細を見る」ボタン → `/slots/{slotId}`へ遷移

4. 空状態
   - 枠がない場合: "予約可能な枠がありません"

### デザイン要件
- レスポンシブ対応（モバイル、タブレット、デスクトップ）
- カードは1行に1〜3枚（画面幅により調整）
- ボタンは緑系（予約系）、赤系（キャンセル系）
- 残席数が少ない（30%以下）場合は警告色表示

### 機能
- ページ読み込み時にAPI呼び出し
- フィルタ変更時に再検索
- ローディング表示（スピナー）
- エラー時のエラーメッセージ表示
```

# 予約システム - ログイン画面

## 画面：ログイン画面

`/login`
