## カスタム例外一覧

### 1. BusinessException (基底クラス)

**パッケージ**: `com.example.reservation.exception`

**用途**: すべてのビジネスロジック例外の基底クラス

**実装**:
```java
package com.example.reservation.exception;

public abstract class BusinessException extends RuntimeException {

    private final String errorCode;

    public BusinessException(String errorCode, String message) {
        super(message);
        this.errorCode = errorCode;
    }

    public BusinessException(String errorCode, String message, Throwable cause) {
        super(message, cause);
        this.errorCode = errorCode;
    }

    public String getErrorCode() {
        return errorCode;
    }
}
```

### 2. ResourceNotFoundException

**HTTPステータス**: 404 Not Found

**エラーコード**: `NOT_FOUND`

**用途**: リソースが存在しない

**実装**:
```java
package com.example.reservation.exception;

public class ResourceNotFoundException extends BusinessException {

    public ResourceNotFoundException(String resourceName, Long id) {
        super("NOT_FOUND", resourceName + "(id=" + id + ")が見つかりません");
    }

    public ResourceNotFoundException(String message) {
        super("NOT_FOUND", message);
    }
}
```

**使用例**:
```java
Slot slot = slotRepository.findById(slotId)
    .orElseThrow(() -> new ResourceNotFoundException("予約枠", slotId));
```

## グローバル例外ハンドラ

### GlobalExceptionHandler.java

**パッケージ**: `com.example.reservation.controller.advice`

**実装**:
```java
package com.example.reservation.controller.advice;

import com.example.reservation.dto.response.ErrorResponse;
import com.example.reservation.exception.*;
import jakarta.persistence.OptimisticLockException;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.security.access.AccessDeniedException;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.HashMap;
import java.util.Map;

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    // ========================================
    // ビジネス例外（BusinessException継承）
    // ========================================

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleResourceNotFound(
        ResourceNotFoundException ex
    ) {
        log.warn("Resource not found: {}", ex.getMessage());
        ErrorResponse error = ErrorResponse.builder()
            .code(ex.getErrorCode())
            .message(ex.getMessage())
            .build();
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(error);
    }

    @ExceptionHandler({
        SlotFullException.class,
        DuplicateReservationException.class,
        DuplicateEmailException.class,
        InvalidCapacityChangeException.class
    })
    public ResponseEntity<ErrorResponse> handleConflict(
        BusinessException ex
    ) {
        log.warn("Conflict error: {}", ex.getMessage());
        ErrorResponse error = ErrorResponse.builder()
            .code(ex.getErrorCode())
            .message(ex.getMessage())
            .build();
        return ResponseEntity.status(HttpStatus.CONFLICT).body(error);
    }

    @ExceptionHandler({
        CancelDeadlinePassedException.class,
        ReservationDeadlinePassedException.class,
        SlotNotOpenException.class
    })
    public ResponseEntity<ErrorResponse> handleGone(
        BusinessException ex
    ) {
        log.warn("Resource gone: {}", ex.getMessage());
        ErrorResponse error = ErrorResponse.builder()
            .code(ex.getErrorCode())
            .message(ex.getMessage())
            .build();
        return ResponseEntity.status(HttpStatus.GONE).body(error);
    }

    @ExceptionHandler(InvalidTokenException.class)
    public ResponseEntity<ErrorResponse> handleInvalidToken(
        InvalidTokenException ex
    ) {
        log.warn("Invalid token: {}", ex.getMessage());
        HttpStatus status = "TOKEN_EXPIRED".equals(ex.getErrorCode())
            ? HttpStatus.GONE
            : HttpStatus.BAD_REQUEST;

        ErrorResponse error = ErrorResponse.builder()
            .code(ex.getErrorCode())
            .message(ex.getMessage())
            .build();
        return ResponseEntity.status(status).body(error);
    }

    @ExceptionHandler(UnauthorizedException.class)
    public ResponseEntity<ErrorResponse> handleUnauthorized(
        UnauthorizedException ex
    ) {
        log.warn("Unauthorized: {}", ex.getMessage());
        ErrorResponse error = ErrorResponse.builder()
            .code(ex.getErrorCode())
            .message(ex.getMessage())
            .build();
        return ResponseEntity.status(HttpStatus.UNAUTHORIZED).body(error);
    }

    // ========================================
    // Spring標準例外
    // ========================================

    @ExceptionHandler(OptimisticLockException.class)
    public ResponseEntity<ErrorResponse> handleOptimisticLock(
        OptimisticLockException ex
    ) {
        log.warn("Optimistic lock conflict: {}", ex.getMessage());
        ErrorResponse error = ErrorResponse.builder()
            .code("CONCURRENT_ACCESS")
            .message("同時にアクセスがありました。再度お試しください")
            .build();
        return ResponseEntity.status(HttpStatus.CONFLICT).body(error);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ErrorResponse> handleValidationErrors(
        MethodArgumentNotValidException ex
    ) {
        log.warn("Validation error: {}", ex.getMessage());

        Map<String, String> details = new HashMap<>();
        for (FieldError error : ex.getBindingResult().getFieldErrors()) {
            details.put(error.getField(), error.getDefaultMessage());
        }

        ErrorResponse error = ErrorResponse.builder()
            .code("VALIDATION_ERROR")
            .message("入力内容に誤りがあります")
            .details(details)
            .build();
        return ResponseEntity.status(HttpStatus.BAD_REQUEST).body(error);
    }

    @ExceptionHandler(AccessDeniedException.class)
    public ResponseEntity<ErrorResponse> handleAccessDenied(
        AccessDeniedException ex
    ) {
        log.warn("Access denied: {}", ex.getMessage());
        ErrorResponse error = ErrorResponse.builder()
            .code("FORBIDDEN")
            .message("この操作を実行する権限がありません")
            .build();
        return ResponseEntity.status(HttpStatus.FORBIDDEN).body(error);
    }

    // ========================================
    // その他すべての例外
    // ========================================

    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponse> handleGenericException(
        Exception ex
    ) {
        log.error("Unexpected error occurred", ex);
        ErrorResponse error = ErrorResponse.builder()
            .code("INTERNAL_SERVER_ERROR")
            .message("エラーが発生しました。しばらくしてから再度お試しください")
            .build();
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
            .body(error);
    }
}
```

## エラーレスポンス形式

### ErrorResponse.java

**パッケージ**: `com.example.reservation.dto.response`

**実装**:
```java
package com.example.reservation.dto.response;

import lombok.AllArgsConstructor;
import lombok.Builder;
import lombok.Data;
import lombok.NoArgsConstructor;

import java.util.Map;

@Data
@Builder
@NoArgsConstructor
@AllArgsConstructor
public class ErrorResponse {

    /**
     * エラーコード（大文字スネークケース）
     */
    private String code;

    /**
     * ユーザー向けエラーメッセージ（日本語）
     */
    private String message;

    /**
     * 詳細エラー（フィールド別）
     * バリデーションエラー時に使用
     */
    private Map<String, String> details;

    // detailsなしのコンストラクタ用ヘルパー
    public static ErrorResponse of(String code, String message) {
        return ErrorResponse.builder()
            .code(code)
            .message(message)
            .build();
    }
}
```

#### 単純なエラー

## 例外処理フロー

### 処理フロー図

```
Controller
    │
    │ メソッド実行
    ▼
Service
    │
    │ ビジネスロジック実行
    │
    ├─ ビジネスルール違反？
    │   ├─ YES → throw SlotFullException()
    │   └─ NO  → 処理続行
    │
    ├─ リソース未発見？
    │   ├─ YES → throw ResourceNotFoundException()
    │   └─ NO  → 処理続行
    │
    ▼
Repository
    │
    │ DB操作
    │
    ├─ 楽観ロック競合？
    │   └─ YES → throw OptimisticLockException
    │
    ▼
    成功
    │
    │
    ▼
Controller
    │
    │ レスポンス返却
    │
    ▼
Client


【例外が発生した場合】

Service/Repository
    │
    │ throw Exception
    │
    ▼
GlobalExceptionHandler
    │
    │ @ExceptionHandler でキャッチ
    │
    ├─ ログ出力（ログレベル: WARN or ERROR）
    │
    ├─ ErrorResponse生成
    │   ├─ code
    │   ├─ message
    │   └─ details (任意)
    │
    ├─ HTTPステータスコード決定
    │
    ▼
ResponseEntity<ErrorResponse>
    │
    │ JSON形式でクライアントへ返却
    │
    ▼
Client
    │
    │ エラー表示
```
