## バリデーション概要

### バリデーション層

バリデーションは2つの層で実施します：

1. **入力バリデーション（DTOレベル）**
   - Jakarta Validation（`@Valid`, `@NotNull`等）を使用
   - リクエストの形式・型・必須チェック
   - Controllerで実行（`@Valid`アノテーション）

2. **ビジネスルール（サービスレベル）**
   - ビジネスロジックに基づく検証
   - DBデータとの整合性チェック
   - Serviceで実行（カスタム実装）

## 入力バリデーション（DTOレベル）

### 使用するアノテーション

| アノテーション | 用途 | 例 |
|--------------|------|-----|
| `@NotNull` | NULL不可 | `@NotNull Long slotId` |
| `@NotBlank` | 空文字列・NULL不可 | `@NotBlank String email` |
| `@Email` | メール形式 | `@Email String email` |
| `@Size` | 文字列長 | `@Size(min=8) String password` |
| `@Min` / `@Max` | 数値範囲 | `@Min(1) Integer capacity` |
| `@Positive` | 正の数 | `@Positive Integer durationMinutes` |
| `@Future` | 未来日時 | `@Future LocalDateTime startAt` |
| `@Pattern` | 正規表現 | `@Pattern(regexp="...") String phone` |

```java
package com.example.reservation.dto.request;

import jakarta.validation.constraints.Email;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.Size;
import lombok.Data;

@Data
public class SignupRequest {

    @NotBlank(message = "メールアドレスは必須です")
    @Email(message = "メールアドレスの形式が不正です")
    private String email;

    @NotBlank(message = "パスワードは必須です")
    @Size(min = 8, message = "パスワードは8文字以上である必要があります")
    private String password;

    @NotBlank(message = "氏名は必須です")
    @Size(max = 100, message = "氏名は100文字以内である必要があります")
    private String name;
}
```

**バリデーションルール**:
- email: 必須、メール形式
- password: 必須、8文字以上
- name: 必須、100文字以内

## ビジネスルール（サービスレベル）

### 1. 予約作成時のビジネスルール

**処理順序**:

```java
@Transactional
public ReservationResponse createReservation(Long slotId, Long userId) {

    // 1. 予約枠の存在チェック
    Slot slot = slotRepository.findById(slotId)
        .orElseThrow(() -> new ResourceNotFoundException("予約枠", slotId));

    // 2. ステータスチェック
    if (!slot.isOpen()) {
        throw new SlotNotOpenException();
    }

    // 3. 予約受付期限チェック（開始24時間前まで）
    LocalDateTime now = LocalDateTime.now();
    if (!slot.canReserve(now)) {
        throw new ReservationDeadlinePassedException();
    }

    // 4. 定員チェック（楽観ロック前）
    Long reservedCount = reservationRepository.countBySlotIdAndStatus(
        slotId, ReservationStatus.RESERVED
    );
    if (reservedCount >= slot.getCapacity()) {
        throw new SlotFullException();
    }

    // 5. 重複予約チェック
    boolean alreadyReserved = reservationRepository.existsBySlotIdAndUserIdAndStatus(
        slotId, userId, ReservationStatus.RESERVED
    );
    if (alreadyReserved) {
        throw new DuplicateReservationException();
    }

    // 6. 予約作成（楽観ロックで定員超過を絶対防止）
    // ...
}
```

**ビジネスルール一覧**:

| ルールID | ルール内容 | 違反時の例外 |
|---------|-----------|-------------|
| BR-R01 | 予約枠が存在すること | ResourceNotFoundException |
| BR-R02 | 予約枠のステータスがOPENであること | SlotNotOpenException |
| BR-R03 | 開始24時間前までに予約すること | ReservationDeadlinePassedException |
| BR-R04 | 定員に空きがあること | SlotFullException |
| BR-R05 | 同一ユーザーが同一枠に重複予約していないこと | DuplicateReservationException |

### 2. 予約キャンセル時のビジネスルール

```java
@Transactional
public ReservationResponse cancelReservation(Long reservationId, Long userId) {

    // 1. 予約の存在チェック
    Reservation reservation = reservationRepository.findById(reservationId)
        .orElseThrow(() -> new ResourceNotFoundException("予約", reservationId));

    // 2. 所有者チェック
    if (!reservation.getUser().getId().equals(userId)) {
        throw new AccessDeniedException("他人の予約をキャンセルすることはできません");
    }

    // 3. ステータスチェック
    if (reservation.getStatus() != ReservationStatus.RESERVED) {
        throw new BusinessException("ALREADY_CANCELLED", "既にキャンセルされています");
    }

    // 4. キャンセル期限チェック（開始24時間前まで）
    LocalDateTime now = LocalDateTime.now();
    if (!reservation.canCancel(now)) {
        throw new CancelDeadlinePassedException();
    }

    // 5. キャンセル実行
    // ...
}
```

**ビジネスルール一覧**:

| ルールID | ルール内容 | 違反時の例外 |
|---------|-----------|-------------|
| BR-C01 | 予約が存在すること | ResourceNotFoundException |
| BR-C02 | 予約の所有者であること | AccessDeniedException |
| BR-C03 | 予約ステータスがRESERVEDであること | BusinessException |
| BR-C04 | 開始24時間前までにキャンセルすること | CancelDeadlinePassedException |

## カスタムバリデーション

### 1. @ValidSlotDateTime（開始 < 終了チェック）

**アノテーション定義**:

```java
package com.example.reservation.validation;

import jakarta.validation.Constraint;
import jakarta.validation.Payload;

import java.lang.annotation.*;

@Target({ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Constraint(validatedBy = SlotDateTimeValidator.class)
@Documented
public @interface ValidSlotDateTime {

    String message() default "開始日時は終了日時より前である必要があります";

    Class<?>[] groups() default {};

    Class<? extends Payload>[] payload() default {};
}
```

**バリデーター実装**:

```java
package com.example.reservation.validation;

import com.example.reservation.dto.request.CreateSlotRequest;
import com.example.reservation.dto.request.UpdateSlotRequest;
import jakarta.validation.ConstraintValidator;
import jakarta.validation.ConstraintValidatorContext;

import java.time.LocalDateTime;

public class SlotDateTimeValidator implements ConstraintValidator<ValidSlotDateTime, Object> {

    @Override
    public boolean isValid(Object value, ConstraintValidatorContext context) {
        if (value == null) {
            return true;
        }

        LocalDateTime startAt = null;
        LocalDateTime endAt = null;

        if (value instanceof CreateSlotRequest request) {
            startAt = request.getStartAt();
            endAt = request.getEndAt();
        } else if (value instanceof UpdateSlotRequest request) {
            startAt = request.getStartAt();
            endAt = request.getEndAt();
        }

        // 両方NULLまたは片方NULLの場合はOK（他のバリデーションでチェック）
        if (startAt == null || endAt == null) {
            return true;
        }

        // 開始 < 終了であること
        return startAt.isBefore(endAt);
    }
}
```

### 定員超過防止の多層防御

予約システムの最重要ルール「定員超過の絶対防止」は、以下の3層で防御します：

1. **事前チェック**（Service層）
   ```java
   if (reservedCount >= slot.getCapacity()) {
       throw new SlotFullException();
   }
   ```

2. **楽観ロック**（JPA）
   ```java
   @Version
   private Long version;
   ```

3. **UNIQUE制約**（DB）※部分インデックス
   ```sql
   CREATE UNIQUE INDEX idx_reservations_unique_active
   ON reservations (slot_id, user_id)
   WHERE status = 'RESERVED';
   ```

**どれか1つでも失敗すれば予約は作成されません！**
